07
Host and USB modes

          
Connect updated firmware to configure modes.

          

            
            
          

          
Automatic starts in HID. Only an Xbox 360 XSM3 signature selects the XInput profile and limits MODE to Guitar Hero ↔ Rock Band. An unknown host keeps all three modes; there is no timeout-based switch. If Xbox does not request XSM3 in HID, use MODE or XInput only. The selected XInput profile applies to detection and startup in XInput only.

          
Editor access: hold Start + Back when powering on the Pico, without MODE. This forces USB HID and enables all three modes for that session only, without changing saved settings. The Bluetooth editor connection remains available in any USB mode.

08
Event LEDs

          
Connect updated firmware to configure outputs.

          

          
Select multiple events for the same LED output. Priority: low battery, selected Bluetooth state, USB mode. The Bluetooth state keeps its blink pattern, including off intervals. Waiting (radio active without discovery or connection) pulses every 3 seconds. Searching: dim blink (13%) every 1.6 s. Connecting/pairing: bright blink every 0.3 s. Full status combines these effects and stays on when connected; Bluetooth off turns the LED off. Effects require updated firmware and work on the guitar and Pico W receiver. Onboard LED needs no external LED: on Pico W it blinks slowly or quickly at fixed brightness; on standard Pico it uses GP25 and supports PWM. The warning needs the battery monitor enabled and is suspended when VBUS is present. Save before switching to XInput. Disabled frees the GPIO. Use an external LED with a series resistor; GPIOs use 3V3. Do not connect an output directly to GND.

          
LEDs: no live reading.

          

          
        

        

          
09
Low battery · VSYS

          
Connect updated firmware to configure the battery.

          

            
            

              
              
              
            

          

          
Measures VSYS internally without occupying GP26–GP28. The battery estimate adds diode correction to the VSYS voltage. Adjust using a multimeter. 1000 mV = 1 V. For a single-cell lithium battery; the initial threshold is adjustable and does not replace discharge protection.

          
With USB/VBUS power present, the warning is suspended and VSYS is not shown as battery voltage. The TP4056 charging circuit is not monitored. To use a warning LED, select Low battery in Event LEDs and save both sections.

          
Battery: no live reading.

10
Bluetooth HID · Pico W

          
This firmware receives an updated Vibetar guitar and sends controls over USB HID, Guitar Hero XInput, or Rock Band XInput. Open pairing on the guitar, click Search guitars below, and choose Connect guitar; the receiver saves the bond after receiving controls and reconnects automatically. The GPIOs, ADCs, and LEDs shown here belong to the receiver. Configure buttons and sensors on the guitar itself. Disable guitar USB priority if it stays connected to a host. The receiver accepts one guitar at a time.

          

          

            
            
          

          
Pair “Vibetar Guitar” in your computer's Bluetooth settings. Enabling Bluetooth or starting with it saved allows new pairing for 120 seconds. Previously paired devices can then reconnect. The guitar accepts one Bluetooth link at a time and stops advertising while connected. Opening pairing closes the current link after 3 seconds and makes the guitar available again; disconnect the previous host to prevent automatic reconnection. Bluetooth uses HID; Guitar Hero and Rock Band XInput remain available over USB.

          
With USB priority, Bluetooth stays connected and sends neutral controls while USB is enumerated. A USB charger without a host does not pause controls. The editor also works over Bluetooth HID when the system exposes the configuration collection to WebHID. Pair on the computer first, then click Connect Pico. Initially enable Bluetooth over USB.

          

            
Guitars found by the receiver

            
Connect this receiver to the editor over USB. Open pairing on the guitar and click Search guitars. The list comes from the receiver radio without using the computer's Bluetooth. To switch guitars, disconnect the current link. A guitar already connected to the computer is unavailable to the receiver.
